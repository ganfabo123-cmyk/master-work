# 行为目标与执行逻辑双实验结果包

本包包含同一批输入切片上的两套独立实验。

- `results/forward/`：正向目标/逻辑分组，最大化高相似轨迹的共同覆盖。
- `results/reverse/`：反向目标/逻辑分组，按不相似关系构造多样性分组。
- `results/shared/`：事件表示、相似度矩阵和领域特征配置。
- `sessions/`：原始切片 JSON，共复制全部输入切片。
- `session-index.jsonl`：切片文件与四类实验归属的索引。
- `manifest.json`：输入、参数和实验说明。

正向和反向共享表示，但使用独立的分组目标和分组过程，不能把其中一套当作另一套的后处理。
