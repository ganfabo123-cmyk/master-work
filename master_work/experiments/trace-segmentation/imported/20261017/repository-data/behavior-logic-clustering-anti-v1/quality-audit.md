# 反向行为聚类质量审计

## 口径

本目录中的 `target-clusters.json` 和 `logic-clusters.json` 仍是正向相似聚类。`target-reverse-clusters.json` 和 `logic-reverse-clusters.json` 是本轮真正的反向结果：它们先从每个视图相似度的低 10% 尾部提取不可同类证据，再把低相似轨迹主动压入均衡的多样性包。包内允许混杂，不能把包解释成“成员已经相似”。

## 覆盖

- 8 个细领域全部运行；
- 314 条领域成员全部进入反向包；
- 目标反向共 34 个包，逻辑反向共 18 个包；
- 没有 residual；
- D007 目标为 3 包（9、9、9），逻辑为 2 包（14、13）。

## 结果判断

这版已经满足“按目标和按执行逻辑分别生成反向包”的实验目标。目标包的组内平均相似度约为 0.01～0.04，确实把不同目标压在一起；逻辑包的组内平均相似度约为 0.21～0.29，仍保留一定执行流程共性，但不再把同一套 Read/Edit/Test 流程强行细碎拆开。包大小接近均衡，适合后续把一个包作为 LLM 的多样性上下文单元。

## 需要保留的限制

反向包只证明“按当前数学表示主动收集差异”，不证明其中存在同一个 Skill。领域成员本身允许重叠，D007 等领域可能带入跨领域轨迹；后续 LLM 仍应读取包内代表首句、证据词和操作序列来判断是否有可抽象的共性。低 10% 是无监督切分参数，后续可用稳定性实验替换，但本轮没有加入任何 LLM 或 embedding 调用。
