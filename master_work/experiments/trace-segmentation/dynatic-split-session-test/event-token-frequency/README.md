# 事件级词频统计

97 个切片，18100 个去重事件。

- `events.jsonl`：一行一个事件，保留源位置、类型、正文和参数各自词频及合计。
- `slice-events.json`：切片到有序事件 ID 的映射，含核心区间与重叠区间位置。
- `by-category.json`：按精确事件类型汇总词频和词出现的事件数，均排除 overlap 重复。
- `summary.json`：数量、分词规则、统计口径和输入目录。

正文与工具参数值计数；参数键、工具名、角色、事件类型等只作元数据，不混入词频。默认不计独立符号，保留大小写，中文连续字符为一项；token 是正则词项，不是模型 token。`payload_not_exported` 表示事件没有可统计字段，不代表原始行为没有内容。本次输入的工具返回及多数 thinking 事件没有导出正文。
