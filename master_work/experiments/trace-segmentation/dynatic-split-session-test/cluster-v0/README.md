# 聚类 v0.2

完全本地、确定性。先用共享任务词倒排表生成候选切片对，再对任务词、动作邻近词、操作+文件名、操作+文件类型分别计算余弦相似度。固定权重和阈值见 config.json。只有任务词与至少一个操作视角同时达标才连边；同会话要求更高的任务词相似度，跨会话要求更强的具体操作证据。每个最大完全子图形成一个初始候选，避免仅靠 A-B-C 链条把不相似的 A 与 C 合并。候选证据分取簇内最弱一对，结合任务词、具体操作和综合相似度；跨会话有少量奖励。只把证据分达到 config.json 门槛、且至少由两个不同会话支持的候选写入 clusters.json 和 assignments.json；其余保留在 deferred-candidates.json，并记录暂缓原因。一个切片可属于多个簇；未入正式簇的切片列入 unclustered.json。证据分未经人工标注校准，不是准确率；跨会话也可能是同一项目，过线簇仍需检查是否含有多任务切片。相同会话的连续切片，即使分数高，也只能当作候选。
