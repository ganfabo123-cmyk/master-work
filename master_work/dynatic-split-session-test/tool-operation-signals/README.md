# 工具操作与对象信号

读取事件级统计中的切片映射，再只看原始切片核心区间的工具调用。Edit/Write/Read/Grep/Glob 使用已知参数字段；Bash/PowerShell 按命令分隔符解析常见命令。路径统一取小写文件名，保留扩展名，舍弃父目录与不确定的目录参数。另列文件类型与操作+文件类型计数，便于跨项目比较。每个事件对同一操作、目标或组合最多计一次。`tool-events.jsonl` 提供可追溯事件；`slice-tool-signals.jsonl` 汇总切片；Markdown 便于查看。命令解析是保守的文本规则，不执行命令，也不从工具返回推断成功。操作与文件目标来自同一命令段；复杂脚本仍可能产生误配。
