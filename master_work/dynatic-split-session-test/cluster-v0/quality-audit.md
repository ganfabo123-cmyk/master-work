# 97 个切片的聚类质量审查（v0.2）

当前是零模型调用的选择性聚类实验。16 个初始候选中，证据分达到 0.75 的有 10 个；再要求至少两个不同会话，只有 1 个候选（P006）进入 `clusters.json`。该门槛用于减少误聚，0.75 不是可信概率，也未经人工标注校准。

## 通过门槛的 C001 / P006

两个切片都出现读取、修改 `vercel.json`，共同主题可描述为“调整 Vercel 静态站点配置”。`11ef2190.../segment-01` 的核心部分在事件 26 读取该文件、事件 54 修改构建设置；核心部分没有人类 `user_text`。`d4c4d47d.../segment-04` 的用户在事件 478 反馈 CSS、JS、字体加载异常；事件 483–515 包括查看 Vercel 文档、读取和修改 `vercel.json`。这支持一个共同**子行为**，不支持认为整个切片都在解决同一任务。

主要限制：两个会话都操作 `BentoFolio` 项目，并非跨项目复现；第二个切片还包括 favicon、链接、项目列表等其他需求。因而 C001 适合优先审查或进一步抽取事件片段，暂不能直接当作干净的 skill 训练样本。

## 高分但暂缓的例子

| 候选 | 证据分 | 人工检查所见 |
|---|---:|---|
| P004 | 0.900 | 同一 Peppertino 项目中处理字体与任务栏图标，文件重叠并不等于同一行为。 |
| P010 | 0.874 | 同一 FrostCore 项目的不同开发阶段：内存/生命周期与解析/字节码边界。 |
| P013 | 0.815 | 同一故事网站中修时间线与新增 Books 页面；共享角色词和文件带来高分。 |
| P014 | 0.811 | 同一 Yggdrasil 项目的库构建与目录、`.gitignore`、README 整理。 |

审查结论：目前的分数更能发现“同项目/同文件的相关工作”，不能单独判断“可复用的相同行为”。跨会话硬门槛防住了这批单会话误聚，但尚未解决跨会话、同项目的污染。正式用于大规模 skill 抽样前，需要按用户任务或局部事件片段验证共同操作，并用人工标注小样本估计准确率与覆盖率。
