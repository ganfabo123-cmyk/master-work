# 爱丽舍宫阴影（结构化中文改编数据）

本目录由 Matt Clifford 于 2020 年创作的 *Intrigue in the Shadow of the Élysée* PDF 解析而来，供 CodeHarness 后续剧本杀 App 使用。

- 原作作者：Matt Clifford
- 原作许可：Creative Commons Attribution-NonCommercial-ShareAlike 4.0 International
- 原始文件：`source.pdf`
- 原始文件 SHA-256：`D7B8F67952AB012DEEBD79021135CCF580A5B22F917F430F371B2E5F2E36AD5E`
- 数据语言：简体中文（依据原文进行结构化翻译和概述）

使用或再分发本目录中的改编数据时，须保留作者署名，限非商业用途，并以相同许可共享。

完整 PDF 实际包含五名可玩角色，并非六名。结构化数据忠实保留这五名角色，没有人为补写角色。

文件说明：

- `manifest.json`：来源、许可、角色与数据文件索引。
- `setting.json`：所有玩家可见的时代背景和公开角色介绍。
- `rules.json`：原作流程与结算规则。
- `moderator_truth.json`：仅主持人/环境可见的固定真相。
- `characters/*.json`：分别投递给对应角色的私密简报。
- `documents/documents.json`：两轮中投递的信件及党章摘录。
- `reveals/*.json`：每轮文档的收件人索引。
