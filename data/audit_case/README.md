`nfi_public_sector/source.html` is the unmodified official source page. The page
contains the whole official collection because GOV.UK does not expose an individual
download for the selected entry. For this project, only the entry identified above
is selected as the audit sample.

The selected case describes undeclared company interests, invoices submitted under
an employee's own authorization threshold, fictitious sender identities, and the
reported investigation outcome. No invoice rows, approval records, policies, or
other evidence have been invented or reconstructed.

This directory contains source material and selection metadata only. Conversion to
an AuditCase State and per-expert Observations is intentionally deferred.
