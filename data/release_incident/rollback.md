# 生产发布回滚 Runbook（虚构材料）

## 立即回滚条件

若新版本发布后五分钟内，核心 API 的 5xx 比例连续两分钟高于 3%，且可以确认该指标从发布开始后明显上升，值班发布负责人可以直接执行回滚，不需要等待产品审批。

执行回滚前必须记录：发布版本号、开始时间、当前 5xx 比例、受影响 API，以及最近一次健康检查结果。

## 回滚后验证

回滚完成后，连续观察核心 API 五分钟。若 5xx 比例恢复至 1% 以下，记录事件并通知发布群；若未恢复，立即转入 P1 事件升级流程。

## 不满足直接回滚条件时

如果 5xx 比例未达到阈值、没有持续两分钟、或异常可能与发布无关，不得凭推测回滚。先收集请求样本、应用错误日志和最近变更，再联系值班技术负责人确认。
