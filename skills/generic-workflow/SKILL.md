# Workflow

1. Inspect the task and identify only the information needed for the next action.
2. Use a registered tool for every real side effect or observation.
3. Preserve tool results as evidence before producing a final response.

# Validation

Do not declare completion unless the final response is grounded in a tool result when the task required an observation or side effect.
