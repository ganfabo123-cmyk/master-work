# Material analysis

For each supplied file or pasted section, extract only evidence relevant to application behavior:

| Concern | Extract |
|---|---|
| Participants | identity, responsibility, whether LLM-controlled |
| Information | content, owner, visibility, release time |
| Sequence | phases, ordering, repetition, branching |
| Choices | who chooses, allowed values, required parameters |
| Rules | precondition, decision, effect, error case |
| Completion | phase completion and application termination |
| Outputs | messages, artifacts, scores, decisions, truth reveal |

Record `source_id`, filename or pasted-section label, and a stable location such as heading, page, scene, or line when available. Distinguish direct evidence from inference. Never infer access permission merely because text was retrievable.
